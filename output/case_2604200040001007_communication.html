    [WER로 덤프 수집]

a.        cmd를 관리자 권한으로 오픈하신 후 하기 명령어를 입력합니다.

 

reg add "HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\Windows Error Reporting\LocalDumps" /v DumpCount /t REG_DWORD /d "10" /f

reg add "HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\Windows Error Reporting\LocalDumps" /v DumpFolder /t REG_EXPAND_SZ /d "C:\Dumps" /f

reg add "HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\Windows Error Reporting\LocalDumps" /v DumpType /t REG_DWORD /d "2" /f

 

b. C:\에 Dumps 폴더를 생성합니다.

c. Regedit 실행하여HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\Windows Error Reporting\LocalDumps이동 후 하기와 같이 설정 값이 잘 적용되었는지 확인합니다.

 

 

d. 문제를 재현하시고 하기 폴더 압축하여 전달 부탁 드립니다.

C:\Dumps

c:\windows\system32\winevt\logs
