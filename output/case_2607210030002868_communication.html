전달주신 자료를 잘 받았습니다.

Azure Linux VM의 성능 상태를 분석하기 위해 추가로 아래와 같이 Performance Diagnostics 도구인 PerfInsights를 Standalone 방식으로 실행하여 진단 자료를 수집해 주시기 바랍니다.

아래 작업은 root 권한 또는 sudo 권한이 있는 계정으로 진행해 주십시오.

 

1. 사전 준비사항

RHEL BYOS 환경에서는 패키지 설치를 위해 서버가 Red Hat Subscription Manager 또는 Red Hat Satellite에 정상적으로 연결되어 있어야 합니다.

다음 명령으로 구독 상태를 확인해 주십시오.

sudo subscription-manager status

 

Python 3, wget 및 tar가 설치되어 있지 않은 경우 다음 명령으로 설치합니다.

sudo yum install -y python3 wget tar

 

과거의 CPU, 메모리, 디스크 사용 이력을 함께 수집하려면 sysstat 패키지가 설치되어 있어야 합니다.

필요 시 다음과 같이 설치 및 활성화합니다.

sudo yum install -y sysstat

sudo systemctl enable --now sysstat

 

임시 작업 디렉터리를 생성한 후 PerfInsights를 다운로드합니다.

sudo mkdir -p /tmp/PerfInsights

sudo chmod 755 /tmp/PerfInsights

cd /tmp/PerfInsights

wget https://download.microsoft.com/download/9/F/8/9F80419C-D60D-45F1-8A98-718855F25722/PerfInsights.tar.gz

 

다운로드한 파일의 압축을 해제합니다.

tar xzvf PerfInsights.tar.gz

 

압축 해제 후 perfinsights.py 파일이 위치한 디렉터리로 이동합니다.

find /tmp/PerfInsights -name perfinsights.py

cd <perfinsights.py 파일이 위치한 디렉터리>

 

2. 성능 저하 구간 수집

CPU, 메모리, 디스크 또는 네트워크 성능 저하 현상을 분석하기 위해 문제가 발생하거나 재현되는 시간에 다음 명령을 실행합니다.

30분간 수집하는 예시는 다음과 같습니다.

sudo python3 perfinsights.py -r vmslow -d 30M -a -o /tmp/perfinsights-output

 

수집이 완료되면 지정한 출력 디렉터리에 다음 형식의 압축 파일이 생성됩니다.

PerformanceDiagnostics_yyyy-MM-dd_hh-mm-ss-fff.tar.gz

 

생성된 다음 파일을 이전에 공유드린 링크로 업로드해 주시기 바랍니다.

현재 OS 디스크의 성능 한도는 500 IOPS로 구성되어 있습니다.

현재 Azure 성능 차트만으로는 azuremonitoragent 또는 mdatp가 직접적인 원인인지, 다른 프로세스나 애플리케이션이 디스크 I/O를 발생시켰는지까지 확인이 어렵고,

단순히 디스크 용량만 확대하기보다는, 현재의 500 IOPS보다 높은 IOPS 및 처리량을 제공하는 디스크 SKU 또는 성능 티어로 변경하는 것이 필요합니다.

실제 디스크 성능 한도 도달 여부

특정 프로세스의 비정상적인 디스크 I/O 발생 여부

mdatp 또는 azuremonitoragent의 영향 여부

애플리케이션 및 시스템 로그의 과도한 생성 여부

파일 시스템 또는 메모리 부족에 따른 스왑 I/O 발생 여부

 

SOS Report를 전달해 주시면 해당 시간대의 시스템 로그, 디스크 상태, 파일 시스템, 프로세스 및 에이전트 정보를 추가로 분석하여 안내드리겠습니다.

다만, 디스크 변경 전 SOS Report와 프로세스별 I/O 사용량을 먼저 확인하여 다음 항목을 구분하는 것이 필요합니다.

실제 디스크 성능 한도 도달 여부

mdatp 또는 azuremonitoragent의 영향 여부

애플리케이션 및 시스템 로그의 과도한 생성 여부

파일 시스템 또는 메모리 부족에 따른 스왑 I/O 발생 여부
