문의사항: 

App Routing Add-on (Managed NGINX) 26년11월까지 지원종료 예정을 확인되어 App Routing Gateway API 전환을 준비중에 있습니다.

아래와 같이 ingress 내 annotation을 적용 운영중에 있습니다. Gateway API 설정 시 아래의 annotation 설정이 가능한 영역인건지, 가이드 기술지원 요청 드리겠습니다.

 

  annotations:

문의주신 ingress-nginx 에서 사용되던 annotations 들은 현재 app routing gateway api에서는 사용이 불가한 상황입니다.

기본적으로 아래와 같은 crd들만 제공되고 있으며

```

gatewayclasses.gateway.networking.k8s.io                           2025-08-29T17:52:36Z

gateways.gateway.networking.k8s.io                                2025-08-29T17:52:36Z

grpcroutes.gateway.networking.k8s.io                              2025-08-29T17:52:36Z

httproutes.gateway.networking.k8s.io                              2025-08-29T17:52:37Z

referencegrants.gateway.networking.k8s.io                          2025-08-29T17:52:37Z

```

https://learn.microsoft.com/en-us/azure/aks/managed-gateway-api#verify-managed-gateway-api-crd-installation

실제 공유해주신 annotation에 부합되는 설정을 위해서는 envoyfilter나 DestinationRule 같은 crd가 필요하여 

이로 인해 annotation이 매칭되는 기능을 사용할수는 없는 상황입니다.

 

다만, 마지막으로 추가해주신 ssl-redirect의 경우는 아래 소개된 httproute 에 requestredirect filter type을 통해 구현이 가능해보입니다.

https://gateway-api.sigs.k8s.io/guides/user-guides/http-redirect-rewrite/#redirects
