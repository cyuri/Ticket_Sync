문의하신 사항에 대해 아래와 같이 정리합니다. 내용을 살펴보시고 잘못 이해하였거나, 궁금하신 점이 있다면 알려주시기 바랍니다. 빠른 확인 및 시스템 기록을 위해 반드시 전체 회신(supportmail@techsupport.microsoft.com 포함)으로 응답 부탁드립니다. 

 

문의 사항: 

Azure Managed Redis에 CMK를 적용할 때 Managed HSM 키 지원 여부가 명확하지 않아 확인 요청을 드리고자 합니다.
Portal에서 적용을 해보면 mhsm key uri로 설정은 되는데 Learn 사이트에서는 정확하게 mhsm이 지원된다는 내용이 없습니다.
또한, Key vault 및 mhsm 키를 통한 CMK 적용 가능 서비스 리스트에도 기존 Azure Cache for Redis만 있고 Azure Managed Redis가 없습니다.
mhsm key 지원 여부과 auto key rotation 가능 여부를 확인 부탁 드립니다.
https://learn.microsoft.com/en-us/azure/redis/how-to-encryption
https://learn.microsoft.com/en-us/azure/security/fundamentals/encryption-customer-managed-keys-support
 

진행 사항: 

Azure Managed Redis에서 CMK 적용시 Managed HSM Key를 사용 가능한지 여부 및 auto key rotation 가능 여부 확인을 요청주신 것으로 이해했습니다.

이 부분은 Key Vault 관련 팀과의 확인도 필요한 부분이라 확인에 다소 시간이 걸리고 있습니다.

확인 후 답변 드리겠습니다.
