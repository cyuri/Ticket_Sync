DEFAULT (-998)는 괄호로 인해 단순 값이 아닌 표현식으로 해석되며, 현재 IcebergCompatV3에서는 표현식 기반 DEFAULT를 지원하지 않아 변환 시 오류가 발생합니다. 반면 DEFAULT -998은 리터럴 값으로 인식되어 정상적으로 변환됩니다.

따라서 임시 조치로는 다음과 d같이 괄호 없이 DEFAULT를 정의하거나, UniForm 활성화 후 DEFAULT를 추가해야 합니다.

DEFAULT -998

또한 Databricks 측에서는 DBR 18.x 최신 유지보수 빌드에서 해당 제한을 보다 명확한 오류 메시지로 안내하도록 개선했다고 합니다.
