파일 첨부 없이 일반 텍스트만 입력하는 경우

새 채팅에서 일반 텍스트만 입력할 때는 오류가 발생하지 않고 정상적으로 응답하는 경우도 있습니다.

다만 파일을 첨부한 요청이 실패한 이후에는 같은 채팅에서 일반 텍스트만 입력해도 다음 오류가 반복적으로 발생합니다.

“문제가 생겼습니다. 문제가 발생했습니다. 다시 시도하시겠습니까?”

따라서 단순히 특정 파일을 처리할 때만 발생하는 오류라기보다, 첨부파일 처리 실패 이후 해당 채팅 또는 Copilot 세션 전체가 정상적으로 응답하지 못하는 증상으로 보입니다.

 

Web 탭과 Work 탭(Work IQ)

Copilot Chat의 Web 탭과 Work 탭 모두에서 동일한 증상이 발생합니다.

모바일 환경에서도 동일하게 확인됩니다.

 

Teams 앱 내 Copilot Chat

Teams 앱 내 Copilot Chat에서도 동일한 오류가 발생합니다.

현재까지 동일 증상을 확인한 환경은 다음 네 가지입니다.

Microsoft Edge 브라우저
Microsoft 365 Copilot 데스크톱 앱
모바일 Copilot
Teams 앱 내 Copilot Chat

 

즉, 특정 브라우저나 특정 앱에만 한정된 문제가 아니며, 접근 가능한 네 가지 환경 모두에서 동일한 증상이 발생하고 있습니다.

특히 파일 첨부 요청이 실패한 이후에는 일반 텍스트 요청까지 동일 오류가 발생하는 부분을 중점적으로 확인 부탁드립니다.

 

요청하신 로그는 금일 퇴근 전까지 파일 업로드 링크를 통해 공유 드리겠습니다.

Step Recorder 로그 수집 방법

(Step Recorder는 사용자가 화면에서 수행한 조작을 클릭 단위로 스크린샷과 설명을 자동 캡처해 재현 절차 문서를 만들어주는 Windows 내장 도구입니다.)

Windows 검색 기능을 통해 단계 레코더 (“Steps Recorder”) 를 조회한 후 실행합니다.

(검색되지 않을 시 실행 창(Windows 키 + R)을 띄운 후 "psr.exe" 입력 및 실행)

 

단계 레코더가 실행되면 우측 상단의 물음표 아이콘을 클릭하신 후, ‘설정’을 클릭합니다.

 

최대 화면 캡처 수를 늘리기 위해 숫자를 ‘100’으로 수정하신 후, ‘확인’을 클릭합니다.

 

문제 재현을 시작하기 전에 ‘Start Record’ 버튼을 눌러 캡쳐를 시작합니다.

  

이후, 문제 상황을 재현하고, 재현이 완료되었으면 ‘Stop Record’를 클릭하여 녹화를 중지합니다.

  

다음과 같이 녹화를 진행한 기간 동안의 내용이 표시됩니다.

  

[Save] 버튼을 클릭하여 Zip 파일로 캡쳐된 내용을 저장하고 zip 파일을 업로드 부탁 드립니다.

[참고] Record steps to reproduce a problem (microsoft.com)

 

HAR 로그 수집 방법

(HAR(HTTP Archive) 로그는 브라우저가 웹 사이트와 주고받은 네트워크 요청 및 응답 정보를 담은 파일로, 웹 관련 문제를 진단하는 데 사용됩니다.)

 

접속한 Web Browser에서 “F12”를 클릭하거나 개발자 도구를 활성화 합니다. 이후Network 탭으로 이동합니다. 이동 후 "Preserve log"를 체크합니다.

 

Network 탭에서 Record 상태가 활성화 상태(빨간색 아이콘 상태)이여야 합니다. Record 를 중지 후 수집된 항목을 전부 삭제, 이후 다시 수집을 시작합니다.

 

증상 재현 후 Network 탭에서 “Export HAR”을 클릭하여 수집된 로그를 저장합니다.
