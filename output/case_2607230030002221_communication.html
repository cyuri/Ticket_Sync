제가 좀 더 명확히 테스트해보고자 어제부터 테스트 환경에 간단히 PVC 를 pod 에 마운트 되어있는 볼륨 2개, pod 마운트가 안되어있는 볼륨 2개 총 4개를 생성하고 cost 비교를 해 보았으나 현재 아래와 같이 불명확하게 요금이 보여지고 있습니다.


Resource group 뷰로 다시보았을 때는 아래와 같이 cost 가 보여졌는데,
보시면 pvc 까지는 만들었으나 pod 에 마운트 하지 않는 볼륨이 pvc-49a~, pvc-17c~ 볼륨이며 각각 10GB, 100GB 짜리이고 현재까지 요금은 0.02 달러, 0.18 달러 즉 총 0.2 달러 입니다.
다만 이 0.2 달러가 위 Kubernetes view 로 볼 때 unallocated charges 의 비용은 0.14 달러이기 때문에 맞지 않아 보입니다.
또한, pod 에 마운트 되어있는 볼륨인 pvc-c91~, pvc-af5~ 역시 10GB, 100GB 이며 현재까지 요금은 0.02 달러, 0.19 달러로 총 0.21 달러이지만, 위 Kubernetes view 에서 cost-test namespace 의 storage 요금을 보시면 0.34 달러로 나오기에 이 또한 맞지 않는 상황 입니다.


제 생각에는 Kubernetes view 로 보여지는 부분은 Cost analysis addon 즉 관련 pod 가 수집해서 전달하는 데이터를 기반으로 하고, Resource group 뷰는 해당 addon 이 아닌 본래 cost 가 수집되는 다른 방식이기에 이와 같은 차이가 보여지는게 아닐까 생각 됩니다.
제가 테스트를 기반으로 고객님께 답변을 드리려 했으나, 현재 테스트를 기반으로 확인 드리기에는 불명확한 부분이 많은 상황이어서, 명확한 확인을 하고자 현재 PG 측에 문의를 해 둔 상황입니다.
조금만 더 기다려 주시면 PG 측 회신 받는대로 업데이트 드릴 수 있도록 하겠습니다.

마이크로소프트 Azure 기술지원에 문의해 주셔서 감사합니다. 저는 본 케이스를 지원할 마이크로소프트 Azure Containers 기술지원팀 박재원 엔지니어 입니다.

 

먼저, 유선으로 통화가 필요할 경우가 존재하여 아래와 사항을 사전에 안내 드립니다.

한국마이크로소프트는 산업안전보건법에 따른 고객 응대근로자 보호조치를 따르고 있습니다. 엔지니어가 고객께 전화를 드릴 때 수신번호 1577-9700 으로 표시되며,

상담 내용은 고객지원 및 서비스 개선 등을 위해 녹음 되며, 관련 법안에 따라 일정기간 보관됩니다.

 

문의사항 내용을 다음과 같이 정리하여 보내 드리니 내용을 살펴보시고 문의사항이나 질문이 있으시면 언제든지 연락주시기 바랍니다.

 

문의사항 : AKS Cost Analysis add-on 사용시 볼륨 관련한 5가지 문의

AKS Cost Analysis Add-on을 활성화하여 Azure Portal의 Kubernetes namespaces 보기를 통해 namespace별 비용을 확인하고 있습니다.
Azure Disk CSI 기반 StorageClass를 사용하여 PVC를 동적으로 프로비저닝하고 있으며 이에 따라 pvc-uuid 형태의 Managed Disk가 AKS 구독의 Node Resource group에 생성되고 있습니다.


하기 문의 드립니다.
- Azure Disk CSI를 통해 동적으로 생성된 Managed Disk 비용이 PVC가 속한 Kubernetes Namespace에 자동으로 할당되는지 확인 부탁드립니다.
- 해당 Managed Disk가 Unallocated charges에 표시되지 않는 경우, 특정 Namespace 비용에 정상적으로 할당된 것으로 판단해도 되는지 확인 부탁드립니다.
- 특정 pvc-uuid Managed Disk의 비용이 어느 Namespace에 할당되었는지 확인할 수 있는 방법 안내 부탁드립니다.
- Managed Disk 비용이 Namespace에 할당되는 경우 어떤 정보(PV의 claimRef.namespace, PVC의 Namespace, PV/PVC UID 등)를 기준으로 매핑되는지 확인 부탁드립니다. 
- PVC 삭제 후 Managed Disk만 남아 있거나 PV가 Released 상태가 되는 경우 이후 Disk 비용은 기존 Namespace에 계속 할당되는지 또는 Unallocated charges로 변경되는지도 확인 부탁드립니다.

 

확인내용 : AKS Cost Analysis add-on 사용시 볼륨 관련하여 위와 같이 5가지 문의를 주셨습니다.

 

주신 문의 내용에 대해 내부적으로 확인 및 제가 필요 테스트를 수행한 후 답변 드리도록 하겠습니다.
