고객 데이터 보호를 위해 마이크로소프트 지원팀에서는 안전한 자료 교환 솔루션인 DTM (Data Transfer & Management)을 통해서만 데이터를 전달받고 있습니다.
첨부 파일을 지원팀에 제공할 때에는 반드시 포털의 지원요청 페이지에서 파일을 업로드해주시거나, 지원 엔지니어로부터 제공 받으신 DTM 링크를 통해 자료 업로드를 부탁드립니다.

[구독 정보]

AzureProductSubscriptionID: 59282147-4e06-47ed-bb04-cd383dd85c09

AzureProductSubscriptionName: sub-az01-rnd-gpu-02

 

[문의 사항]

sub-az01-pg108201-dev-aaip 구독에서 실사용 GPU RI 내역 Cost 확인이 불가합니다. 상위 invoice sections 에서는 확인이 가능한데요. 구독에서는 확인이 불가한건기 확인 요청 드립니다.

 

문의 주신 내용을 [특정 구독 수준에서 예약 Amortized Cost 조회 불가] 문의로 이해하였습니다.

제가 잘못 이해한 부분이 있거나 누락된 사항이 있을 경우 알려주시면 감사하겠습니다.

 

문의 주신 내용과 관련하여 확인한 결과, 구독 Scope에서도 예약의 Amortized Cost조회는 가능합니다. 

현재 저희 측에서 확인한 바로는 해당 구독[d08aebd3-cf19-48ca-be3a-a216a664508b, sub-az01-pg108201-dev-aaip] 수준의 usage report에서는 예약 혜택 Amortized Cost 데이터가 조회되고 있습니다. 

다만 고객님께서 확인하신 특정 GPU RI 내역 또는 특정 기간의 데이터가 구독 수준에서 조회되지 않는 현상에 대해서는 추가 확인이 필요합니다.

조사를 위해 아래 정보를 회신 부탁드립니다.

조회에사용하신 계정의 Email ID

2번 화면 캡처 시 아래 사항이 확인될 수 있도록 부탁드립니다.
