안녕하세요.
마이크로소프트 김성은입니다.

gpt-image-2 이미지 생성 시 로맨스 계열 이미지가 Sexual(성적) 콘텐츠 필터에 걸리는 현상에 대해 문의 주셔서 감사합니다.
결론부터 말씀드리면 콘텐츠 필터의 차단 강도(심각도 임계값)를 조정하여 완화가 가능하며, 방법은 다음과 같습니다.


1. 현재 동작 원인

Microsoft Foundry의 콘텐츠 필터는 이미지 생성 모델에도 동일하게 적용되며, 기본값은 "중간(Medium blocking)" 입니다. 즉 중간·높음으로 판정된 콘텐츠는 차단되고, 낮음·안전은 통과됩니다. 로맨스 포스터 등 경미한 이미지가 medium으로 분류되어 차단되는 것으로 보입니다.


<참고문서>
콘텐츠 필터 구성(클래식) - Microsoft Foundry (classic) portal | Microsoft Learn
"Microsoft Foundry에 통합된 콘텐츠 필터링 시스템은 이미지 생성 모델을 비롯한 핵심 모델과 함께 실행됩니다."

"기본 콘텐츠 필터링 구성은 프롬프트와 완료 모두에 대해 … 중간 심각도 임계값으로 필터링하도록 설정됩니다. 심각도 수준이 중간 또는 높음으로 검색된 콘텐츠는 필터링되는 반면 낮음 또는 안전으로 검색된 콘텐츠는 필터링되지 않습니다."

 

2. 1차 권장 방안 — Sexual 범주를 "Lowest blocking(높음만 차단)"으로 설정

Foundry 포털의 콘텐츠 필터 설정에서 Sexual 범주 슬라이더를 "Lowest blocking" 으로 조정하면 가장 심각한(높음) 콘텐츠만 차단되고 낮음·중간은 통과되어, 경미한 로맨스 이미지의 오탐이 크게 줄어듭니다. (포털 UI의 "Lowest blocking" = 공개 문서상 심각도 임계값 "높음(High)" 과 동일한 설정입니다.)

설정 절차

Microsoft Foundry 로그인 → 프로젝트 선택.
왼쪽 메뉴 Guardrails + 컨트롤 → 콘텐츠 필터 탭 → + 콘텐츠 필터 만들기.
입력/출력 필터 화면에서 Sexual 범주의 Text / Image 토글을 확인하여, 이미지 생성이므로 Image(생성 이미지)의 슬라이더를 "Lowest blocking" 으로 조정합니다. 프롬프트 텍스트도 차단된다면 Text도 함께 낮춰 주세요.
연결 페이지에서 해당 gpt-image-2 배포에 필터를 연결하고 필터 만들기.
이미 배포가 있는 경우: 모델 + 엔드포인트 → 해당 배포 편집 → 생성한 콘텐츠 필터 선택 → 저장.
플레이그라운드에서 로맨스 프롬프트로 재테스트하여 정상 통과하는지 확인.
 

3. 2차 방안 — "Lowest blocking"으로도 부족한 경우, 콘텐츠 필터 해제(off) 검토

위 설정으로도 필요한 이미지가 계속 차단된다면, Sexual 범주 필터를 "필터 없음(off)" 또는 "주석만 달기(Annotate only)" 로 설정하는 방안을 검토하실 수 있습니다. 단, 콘텐츠 필터를 부분/완전 해제하려면 수정된 콘텐츠 필터(Modified Content Filters) 승인이 필요합니다.
