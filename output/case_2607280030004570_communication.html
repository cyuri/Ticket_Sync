안녕하세요 매니저님, 

 

Defender 정의업데이트는 Windows Update기능을 빌려 동작하는 구조입니다.

같은 이유로 디펜더의 업데이트 역시 Windows Update URL을 통해 받아옵니다.

따라서 update.microsoft.com 을 포함한 업데이트 관련 URL역시 connectivity 확보가 필요합니다.

 

Windows 10 이상의 버전은 MDE 에이전트가 OS에 내장이 되어있습니다.

Windows 10 하위 버전은 Azure Monitoring Agent를 통해 MDE기능이 동작합니다.

이러한 이유로 Windows 10 하위 버전의 OS에서는 별도의 URL open이 필요합니다.

 

기존에 Excel파일 형태로 제공되던 URL list는 문서에서는 제공되지 않고 앞서 전달드린 문서를 통해 확인하시는 것이 좋습니다.

다만 이 문서관리는 엔지니어 레벨에서 관리되는 것이 아니기 때문에 이후에는 또 다른 방식으로 변경될 수도 있으니 인지만 해주시기 바랍니다.

 

추가로 안내드렸던 디펜더 정의 업데이트 관리와 관련된 GPO, WSUS와 관련된 내용은 오후에 발송될 종료메일에 추가하여 전달드리도록 하겠습니다.

타사의 WSUS구성 사례나 운영방식은 CSAM이신 황용하 님을 통해 문의해주시면 좋을 것 같습니다.
