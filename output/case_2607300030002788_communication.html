마이크로소프트 애저 기술지원에 문의해 주셔서 감사합니다.

 

저는 본 케이스를 지원할 마이크로소프트 기술지원부 김용출 엔지니어입니다. 

문의사항을 다음과 같이 정리하여 보내드리니 내용을 살펴보시고

문의사항이나 질문이 있으시면 언제든지 연락주시기 바랍니다.

 

고객 데이터 보호를 위해 마이크로소프트 지원팀에서는

안전한 자료교환 솔루션인 DTM(Data Transfer & Management)을 통해서만 데이터를 전달받고 있습니다.

첨부파일을 지원팀에 제공할 때에는 반드시 포털의 지원요청 페이지에서 파일을 업로드해주시거나, 

지원 엔지니어로부터 제공받으신 DTM 링크를 통해 자료 업로드를 부탁드립니다.

 

- 문의사항 : VM 웹사이트 접속 불가

VM에 구성된 웹사이트 접속이 불가해 문의드립니다.

방화벽 오픈 완료하여 Azure 방화벽측으로 통신 정상인거 확인했고,

iptable도 추가해두었는데도 접속이 안되고 있어 네트워크 상태 확인 요청드립니다.

 

[Azure 방화벽 확인 내역]

2026. 7. 28. 오전 9:14:55.971

TCP

10.225.131.85

58167

10.241.132.36

443

Allow

 

- 확인내용 : 해당 VM에 effective route rule 확인 시 10.0.0.0/8 룰을 통해서 10.241.4.132쪽 VPN gateway 연결을 통해서 연결이 될 것으로 보입니다.

VM의 NSG룰은 inbound 허용되어있는 것으로 확인됩니다.

 

- 다음단계 : 확인해주신 Azure 방화벽 확인 부분이 10.241.4.132쪽 VPN gateway 연결 통해서 들어오는 부분의 방화벽인지 확인 부탁드립니다.

VM의 guest OS내에서 웹사이트 접속에 영향을 줄만한 부분 확인을 위해서 아래 명령어 수행 결과 공유 부탁드립니다.

그리고 혹시 80포트도 LISTEN중이라면 80포트로는 정상 접근되는지 확인 부탁드립니다.

# 원격지에서 수행

nc -zv 10.241.132.36 443

또는

curl -vk https://10.241.132.36

 

# 해당 VM에서 수행

ss -lntp | grep 443

curl -vk https://localhost

firewall-cmd --list-all

iptables -L INPUT -n -v

cat /proc/sys/net/ipv6/bindv6only
